# Ícones dos softwares (Projeto Caju)

Coloque aqui os ícones personalizados de cada software exibido na seção
"Projeto Caju". O nome do arquivo (sem extensão, em minúsculas) precisa
corresponder exatamente a um dos nomes abaixo:

- `autocad.png` (ou `.svg` / `.jpg` / `.jpeg` / `.webp`)
- `sketchup`
- `layout`
- `revit`
- `archicad`
- `enscape`
- `lumion`

Formatos aceitos: `.png`, `.svg`, `.jpg`, `.jpeg`, `.webp`.

Assim que um arquivo com o nome correto for adicionado aqui, o site passa a
usá-lo automaticamente no badge daquele software — nenhuma mudança de código
é necessária. Enquanto o arquivo não existir, o badge continua mostrando o
ícone genérico padrão (lucide-react) como substituto.

Recomendação: use imagens quadradas, com fundo transparente, de pelo menos
64x64px, para melhor nitidez no badge (exibido a ~24px).
